## 3. client_dart 增强（T2）

3.1. 新增 `DshConnection`（`lib/src/connection.dart`）——在 `DshClient` 之上补全 Gate-B §3.4 状态机：

```dart
enum ConnPhase { disconnected, connecting, connected, streaming, error }

class DshConnection {
  DshConnection({required String endpoint});   // http://127.0.0.1:<port>
  ConnPhase get phase;
  Stream<ConnPhase> get phases;
  Stream<ServerRequestFrame> get events;       // mux 帧（自动重连 + 续传）
  DshClient get client;                        // unary 调用复用
  Future<void> start();                        // connect + open mux + 重连循环
  Future<void> switchEndpoint(String url);     // 端点热切换（重建流）
  Future<void> close();
}
```

- **重连**：WS 断开/出错 → 指数退避 1s→2s→…≤30s（复位条件：成功进入 streaming 且收到任一帧）；
- **续传**：重连成功后解析 `session/subscribed`（含各会话 lastSeq）→ 与本地 `Map<sessionId,int> _lastSeq` 比对 → 有缺口走 `session.history` 补拉并按 seq 升序补投事件（去重：`event.seq ≤ _lastSeq` 丢弃）；
- **心跳**：≥60s 无任何帧 → 主动断开触发重连循环（服务端无 ping 帧时的保守探活）；
- **端点热切换**：close 旧流 → 重建 client/connection → 重放订阅。

## 4. 消息聚合（T3）

4.1. 新增 `ChatAssembler`（`client_dart/lib/src/assemble.dart`，纯 Dart 无 UI 依赖，golden 单测）：

```dart
class ChatMessage {                       // UI 消息模型
  final String id;                        // step 消息 id 或合成 id
  final Role role;                        // user / assistant / system
  final List<ChatBlock> blocks;           // text / code / toolCall / usage
  final MessageStatus status;             // streaming / done
  final int? seq;                         // 关联事件 seq（去重/排序）
}

class ChatAssembler {
  List<ChatMessage> applyHistory(List<SessionEvent> events);      // 历史装载
  ChatDelta applyEvent(ChatState state, SessionEvent event);      // 直播增量（返回增量描述供 UI 局部刷新）
  int? lastSeq;                                                   // 游标（续传比对）
}
```

4.2. 聚合规则（依据契约 v0.1 §3 实测事件）：

| 事件 | 规则 |
|---|---|
| `user/message` | 追加 user 消息（blocks=[text]） |
| `turn/start` / `step/start` | 开启新 assistant 占位（status=streaming） |
| `assistant/chunk:block-start` | 按 `index` 开新 block（text/code 由 blockType） |
| `assistant/chunk:text-delta` | 向 open block[index] 追加文本（增量） |
| `assistant/chunk:block-end` | 用 `block` 全量落定该 index（防漂移） |
| `assistant/chunk:usage/finish` | usage 附着当前 step；finish → status=done |
| `assistant/message` | **权威落定**：整条替换该 step 的 assistant 消息 |
| `session/title` / `session/projection` | 不进消息流，更新会话列表元数据 |
| `approval/policy` / `permission/*` | 进审批队列（§6），不进消息流 |
| 工具调用帧（T2 抓包确认 type） | 聚合为 toolCall block（名称/参数/结果/耗时） |

4.3. 验收：40KB golden（`session.history.response.json`）聚合结果与 mux 直播重放结果一致（golden 双断言）。

### 5.2 Providers（core/providers.dart）

| provider | 类型 | 说明 |
|---|---|---|
| `nodeEnvProvider` | FutureProvider | NodeEnv.probe（引擎页/实例页共用） |
| `instanceManagerProvider` | Provider | InstanceManager 单例（dispose 挂 app 生命周期） |
| `instanceEventsProvider` | StreamProvider | manager.events（instances 页 listen 局部刷新） |
| `activeEndpointProvider` | Notifier | 活动端点：选中实例推导 or 手动输入（持久化到 settings） |
| `connectionProvider` | Provider | 依赖 activeEndpoint → DshConnection 生命周期（端点变化重建） |
| `sessionsProvider` | Notifier | session.list + projection/title/queue 增量 |
| `chatControllerProvider.family(sessionId)` | Notifier | ChatAssembler 状态 + send/steer/cancel |
| `pendingApprovalsProvider` | Notifier | 审批队列（FIFO，逐个面板处置） |
| `appSettingsProvider` | Notifier | 端口/数据目录/主题/autoStart（shared_preferences 持久化；**消息不持久化**，BQ8） |

### 5.3 页面要点

- **引擎页**：NodeEnv 卡片（node/dsh 版本、DSH_HOME、可写性）+ 版本列表（dist-tags 分组：latest/next/alpha）+ 安装/升级/回滚按钮（InstallService，进行中禁用重复点击）；
- **实例面板**：列表行 = alias/status 徽标/port/pid/启动时长/lastHeartbeat；**事件流驱动刷新**（listen instanceEvents → 定向更新行，不整页 rebuild）；详情页：状态卡 + `LogTail.tail(200)` 日志区（新行自动滚动，可暂停）+ export 按钮 + 启停/重启；
- **对话工作台**：左会话列表（260px，title/running/contextPressure 徽标）｜中消息流（`ListView.builder` + 底部锚定：用户在底部时新消息自动滚动，上翻时不打扰）｜底部输入框（Enter 发送 = queue，Shift+Enter 换行，steer 开关，cancel 按钮）｜**审批浮层**：pendingApprovals 非空时显示于消息流上方（允许/拒绝 → respond）；
- **流式渲染管线**：assembler 增量 → `chatController` 持有 blocks 状态 → 渲染组件按 block 粒度重建（非整列表）；`text-delta` 高频到达做 16ms 合帧（` throttling`）再 setState；
- **设置页**：默认端口（0=自动）/ 数据目录 / 主题（亮暗/跟随系统）/ autoStart 开关（默认关）/ 模型只读列表（`llm/models`）/ 当前活动端点展示。

### 5.4 审批时序（GM3-6）

```
dsh: approval/policy 帧 → WS mux → pendingApprovalsProvider 入队 → UI 浮层
用户点击「允许/拒绝」→ SessionApi.respond(payload=T2 抓包定型) → run 继续
超时/会话关闭 → 面板自动收起（帧带 sessionId 关联）
```

### 5.5 托盘与自启（T8）

- 托盘菜单：`打开主窗`（window show+focus）/ `全部停止`（遍历 InstanceManager 逐个 stop）/ `退出`（先 stop 全部再 close）；
- 最小化行为：设置开关「关闭时最小化到托盘」（默认开）；
- 自启：`launch_at_startup.setEnabled(settings.autoStart)`（默认 false）。
