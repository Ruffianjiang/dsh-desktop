## 1. 背景与定位

1.1. M1（T1–T6）与 M2（F1/F2 库层）已完成并随 PR #6 合入 main。M3 = **L1 UI 层从零实建** + 端到端闭环，出口 = Windows release 产物上完成「**管理 → 启动实例 → 对话 → 工具审批**」闭环（Gate-A §8 M3 出口标准）。

1.2. 底座现状（可直接复用）：

| 层 | 已就绪 | 说明 |
|---|---|---|
| L3 client_dart | `DshClient.call`（REST unary，rpcId 校验）、`openStream`（**WS 下行** `/api/events.mux|host`，实测 426 Upgrade Required → WS 升级，兼容 SSE 风格帧）、`SessionApi`（list/create/history/prompt/cancel） | 实测跑通直播 text-delta 与 history |
| 契约 v0.1 | session 域实测子集 + 40KB 全轮事件 golden + mux 直播抓包 | 事件类型清单齐（assistant/chunk 分态、approval/policy、session/projection…） |
| L2 dsh_manager | NodeEnv.probe / InstallService / VersionCatalog / InstanceSupervisor（守护+事件流）/ LogTail / RegistryStore / InstanceManager（autoStart） | selfcheck 三件套全过 |
| L1 desktop_flutter | **占位** | 本里程碑主体 |

1.3. 底座缺口（M3 需补，属 client_dart/contract 增量）：
1. **连接状态机不完整**：现仅 disconnected/connecting/connected 三态、**无自动重连**（Gate-B §3.4 承诺指数退避 1s→30s、游标去重、心跳未实现）；
2. **契约待补域**：`/api/respond` 应答流（审批回写）、`approval/policy` / `permission/*` 帧语义、`session.prompt mode:"steer"`、subagent/skills 只读域、`llm/models` 只读；
3. **WS 断线语义**：`openStream` 断开即 close，无重订阅/lastSeq 续传（契约 §3 有 `session/subscribed` lastSeq 可用）。

## 3. 总体架构（L1 落地视图）

```
┌─ desktop_flutter (Flutter, Riverpod) ──────────────────────────────────┐
│ app shell（窗口/托盘/路由/主题）                                        │
│ ├ features/engine     引擎管理页   ──→ L2 NodeEnv/InstallService        │
│ ├ features/instances  实例面板     ──→ L2 InstanceManager/事件流/LogTail │
│ ├ features/chat       对话工作台   ──→ L3 SessionApi/WS 事件流/审批     │
│ └ features/settings   设置页        ──→ L2 RegistryStore + 本地偏好      │
│     core/（Riverpod providers、路由、主题、窗口、托盘、DI）              │
└──────────────┬──────────────────────────────────────┬──────────────────┘
               │ 进程管理（dart:io Process）            │ WS/REST（client_dart）
        ┌──────▼───────┐                        ┌─────▼──────────────┐
        │ L2 守护的 dsh │ ── 127.0.0.1:<port> ──→│ /api/rpc + events  │
        └──────────────┘                        └────────────────────┘
```

要点：
1. **UI ↔ dsh 唯一通道是 L3 客户端**（Gate-A §4.1.5 不回退约束）；L2 只负责引擎/实例进程管理，UI 的 instances 页消费 L2 事件流，chat 页只碰 L3；
2. **端点模型**（D8）：设置/实例面板选定「活动端点」= 本机托管实例（从 InstanceManager 状态自动推导 `http://127.0.0.1:<port>`）或手动输入端点；chat 连接随活动端点切换；
3. 状态管理 **Riverpod**（平台 Gate-B BQ2 已确认）；路由方案见 BQ6。

## 4. 关键方案

### 4.1 应用骨架（GM3-1）
- `flutter create -e`（空模板）+ 目录按 Gate-B §5.1（core/features/shared）；
- 窗口：`window_manager`（尺寸/标题/最小化到托盘联动）；托盘：`tray_manager`；自启：`launch_at_startup`（M3-T8 前做 Windows 兼容性实测，Gate-B §5.2 预留项）；
- 主题：亮/暗双主题 + 跟随系统；字体/密度以对话可读性优先。

### 4.2 连接管理增强（GM3-2，client_dart 增量）
- 连接状态机补全为 Gate-B §3.4 全集：`Disconnected→Connecting→Connected→Streaming` + 重连（指数退避 1s→2s→…≤30s）+ `Error/Closed`；
- **lastSeq 续传**：WS 重连后以 `session/subscribed` 的 lastSeq 为游标，缺口走 `session.history` 补拉（契约 §3 已有字段）；
- 心跳探活：WS 层 ping/pong 或空闲超时重连；
- `DshClient` 增加 `endpoint` 热切换（换端口/端点重建流）。

### 4.3 引擎管理页 + 实例面板（GM3-3/4）
- 引擎页：`NodeEnv.probe` 展示 node/dsh 版本与可写目录；VersionCatalog 列表（latest/next/alpha 分组）；安装/升级/回滚按钮（复用 InstallService，进度走 Future 流）；
- 实例面板：`InstanceManager.list/stateOf` 渲染列表；**事件流驱动**（StatusChanged/Heartbeat/Exited 直接刷 UI，不轮询）；详情页含 LogTail `tail(200)` 实时区 + export；启停/重启按钮；
- 「创建实例」表单：profile（默认 web）/端口（0=自动）/数据目录/别名/autoStart。

### 4.4 对话工作台（GM3-5，核心）
- **会话列表**：`session.list` 拉取 + `session/projection`（title/running/contextPressure）增量更新；新建/删除/归档/切换；
- **消息流渲染**：
  - 历史装载：`session.history` 事件流 → **消息聚合纯逻辑**（把 turn/step/user message/assistant chunk|message 聚合为 UI 消息模型；纯 Dart 函数 + golden 单测）；
  - 直播：`session/event` 的 `assistant/chunk.text-delta` 按 block index 增量拼接，`block-end`/`assistant/message` 落定替换（防抖渲染）；
  - 渲染库 **bench 后定**（BQ1）：候选 `flutter_markdown`+代码高亮扩展 vs `gpt_markdown` vs 自研精简渲染；bench 用例 = 50ms 间隔 text-delta × 1000 块 + 20 个代码块高亮 + 滚动锚定，帧率与丢帧为验收；
- **输入**：`session.prompt`（mode 默认 queue，可切 steer）；队列状态用 `session/queue` 帧展示；`session.cancel` 中断按钮。

### 4.5 工具轨迹与审批（GM3-6）
- 工具/命令轨迹：从 `session.history`/直播事件中的工具调用块聚合展示（名称/参数/结果/耗时，折叠态）；
- **审批**：`approval/policy`/`permission/*` 帧 → 右侧/浮层审批面板（允许/拒绝）→ `/api/respond` 回写（契约 §5 待补域，M3-T2 抓包补 golden）；
- 子代理/技能：只读轨迹展示（BQ3）。

### 4.6 设置与系统集成（GM3-7）
- 设置页：默认端口/数据目录/主题/模型只读展示（`llm/models`）/实例默认 autoStart；
- 托盘：最小化到托盘 + 菜单（打开主窗/全部停止/退出）；
- 自启：`launch_at_startup` 注册/注销（默认关，BQ4）。

### 4.7 Windows MVP 产物（GM3-8）
- `flutter build windows --release` → 产物目录打包 zip（含运行说明）；安装器/自动更新留 M4（BQ5）；
- **端到端冒烟**：脚本化（probe_cli 思路延伸）或手动清单：启动 app → 引擎探测 → 建实例 → running → 新建会话 → 发消息 → 流式输出 → 触发一次工具审批 → 批准 → 完成。
